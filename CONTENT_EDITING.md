# Editing the portfolio

1. Open https://app.pagescms.org/ and sign in with GitHub.
2. Install the Pages CMS GitHub App for Jemp72/Emman-personal-portfolio and open the repository on main.
3. Open Portfolio content, edit the relevant fields, and save. Array order controls display order.
4. Wait for the GitHub Pages workflow to finish at https://github.com/Jemp72/Emman-personal-portfolio/actions/workflows/pages.yml.

You can reach the editor from the portfolio’s admin page by typing ↑ ↑ ↓ ↓ ← → ← → B A on the homepage outside Play.

Portfolio content lives in src/content/portfolio.json. Uploads go in public/cms-media. Edit profile information, education, branding, socials, skills, projects, artwork, and certifications from the form. Keep project slugs stable to preserve links. A certificate can use an uploaded file or an external URL. The GitHub repository and the deployed portfolio are public, so only upload files intended for publication.
