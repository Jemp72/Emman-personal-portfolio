**DARS**

DARS (Domestic Abuse Reporting System) is a web application for reporting and managing domestic abuse cases in Tagum City. Residents can submit reports, while staff can monitor cases, update investigation statuses, and record resolutions. It includes role-based access for administrators and barangay operators, real-time updates, staff management, and audit logs.



DARS (Domestic Abuse Reporting System) is a full-stack web application for reporting and managing domestic abuse cases in Tagum City. It uses Vue 3, TypeScript, Vite, and Vue Router for the frontend, with a Node.js and Express REST API connected to MySQL through mysql2.



The system integrates Socket.IO for real-time report updates, Leaflet and OpenStreetMap for incident mapping, GeoJSON and point-in-polygon validation for geographic boundaries, and Chart.js for reporting dashboards. Authentication uses JWT and bcrypt, with role-based access for system administrators, administrators, and barangay operators. MySQL stored procedures, views, and triggers support case management, report status tracking, and audit logging.

Source: https://github.com/5kr1mp/dars

**CLMS**

This Computer Laboratory Management System (CLMS) helps manage laboratory bookings, class schedules, equipment, and office supplies. It also tracks student and guest laboratory usage, giving administrators a central place to monitor resources and daily activities.

The system manages laboratory reservations, class schedules, instructor records, equipment inventory, maintenance status, office supplies, and laboratory utilization logs. It also supports CSV enrollment imports, QR scanning through qr-scanner, public reservation forms, and a student/guest time-in and time-out kiosk. Development tooling includes Composer, npm, Pest, and Laravel Pint.

Source: https://github.com/Jemp72/CLMS-v1

**COZZEE CAFE**

Cozzee Café is a responsive café website designed to showcase the café’s menu, services, and business information while providing customers with an easy way to explore its offerings and get in touch. The website is built using HTML5 for structure, CSS3 for styling and responsive layouts, and JavaScript for interactive features. It is hosted on GitHub Pages, providing free and accessible static website deployment.
